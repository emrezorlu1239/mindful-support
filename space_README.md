# Mindful Support

An experimental, noncommercial AI application for emotional support and general psychoeducation.

**This is not a psychologist, therapist, diagnostic tool, or emergency service. It has no clinical validation.**

- English is the primary interface language.
- Türkçe is available with a language-limitation notice (engineering score 6.4/10 on a small synthetic set).
- No conversation content is stored; session memory is cleared when you end or close the session.
- Appointments are stored temporarily in a local database scoped to your 24-hour session cookie.

See the [repository](https://github.com/emrezorlu1239/mindful-support) for source, evaluation records and limitations.
