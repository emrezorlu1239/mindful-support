# Reviewed reference collection

This collection contains 13 short text excerpts from two National Institute of Mental Health pages. Every item records its canonical URL, publisher, language, content hash, snapshot hash, retrieval time and review scope.

NIMH states that its text is generally public domain unless otherwise indicated. Its images cannot be reused. The selected text is used for general information only, with attribution and links; NIMH does not endorse Mindful. Reuse review was performed by the coding agent, not a clinician. See the [NIMH policy](https://www.nimh.nih.gov/site-info/policies).

The journal bullet includes its original introductory paragraph because three words alone provided insufficient retrieval context. No new medical claims were added.

The SQLite index under ignored data/ contains only these public references and their multilingual E5 vectors. No user messages or query embeddings are saved to this collection. Source changes invalidate the stored corpus hash and require a reviewed rebuild.
